## 2. Persona 1: 零基础入门者 (Beginner)

### 2.1 基本信息

| 属性 | 描述 |
|------|------|
| 年龄 | 18-35岁 |
| 职业 | 学生/白领 |
| 乐器 | 钢琴/吉他 |
| 学习时长 | 0-6个月 |
| 技术水平 | 无音乐基础 |

### 2.2 目标与动机

| 目标 | 动机 |
|------|------|
| 学会基础演奏 | 自我提升、兴趣爱好 |
| 能弹简单曲目 | 社交展示、个人成就感 |
| 建立练习习惯 | 培养自律、时间管理 |

### 2.3 痛点分析

| 痛点 | 严重程度 | 解决方案 |
|------|----------|----------|
| 不知道怎么练 | 高 | 提供入门课程引导 |
| 缺乏反馈 | 高 | 实时音准反馈 |
| 容易放弃 | 高 | 成就激励、打卡系统 |
| 练习效率低 | 中 | 分段练习、纠错流程 |

### 2.4 使用场景

| 场景 | 时间 | 设备 | 频率 |
|------|------|------|------|
| 晚间练习 | 19:00-21:00 | 手机/平板 | 每日30分钟 |
| 周末练习 | 周末下午 | 手机/平板 | 每周2小时 |
| 碎片练习 | 随时 | 手机 | 不定期 |

### 2.5 关键路径

```
校准 → 选择入门曲目 → 练习 → 反复纠错 → 成就激励 → 继续练习
```

### 2.6 付费意愿

| 方案 | 意愿 | 价格敏感度 |
|------|------|------------|
| Free | ✓ | 高 |
| Premium | 低 | $5-10/月可接受 |
| Pro | 无 | 不考虑 |

| 进度追踪繁琐 | 中 | 自动统计、报告导出 |
