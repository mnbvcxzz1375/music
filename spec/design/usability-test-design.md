## 2. SUS问卷设计

### 2.1 System Usability Scale (SUS) 问卷

| 序号 | 问题 | 选项 |
|------|------|------|
| 1 | 我会经常使用这个系统 | 1-5分 |
| 2 | 我发现这个系统 unnecessarily complex | 1-5分 |
| 3 | 我认为这个系统很容易使用 | 1-5分 |
| 4 | 我需要技术人员的帮助才能使用这个系统 | 1-5分 |
| 5 | 这个系统的各项功能整合得很好 | 1-5分 |
| 6 | 我认为这个系统中存在太多不一致的地方 | 1-5分 |
| 7 | 我想象大多数人会很快学会使用这个系统 | 1-5分 |
| 8 | 我发现这个系统非常 cumbersome to use | 1-5分 |
| 9 | 我在使用这个系统时感到非常自信 | 1-5分 |
| 10 | 我需要学习很多东西才能开始使用这个系统 | 1-5分 |

### 2.2 SUS评分计算公式

```
SUS评分 = 
  (Q1 + Q3 + Q5 + Q7 + Q9 - 5) * 2.5 +
  (25 - (Q2 + Q4 + Q6 + Q8 + Q10)) * 2.5

评分范围: 0-100
目标评分: ≥85 (优秀)
```

## 4. 测试流程

### 4.1 测试前准备

1. 签署知情同意书
2. 收集用户基本信息
3. 说明测试目的和流程
4. 强调"这不是测试用户能力"

### 4.2 测试执行

1. 用户自主完成任务
2. 观察员记录行为和表情
3. 用户可随时表达想法
4. 不干预用户操作

### 4.3 测试后访谈

1. 填写SUS问卷
2. 收集用户反馈
3. 讨论遇到的问题
4. 收集改进建议

## 5. 问题记录模板

### 5.1 问题分类

| 类别 | 说明 | 严重程度 |
|------|------|----------|
| 阻碍性问题 | 用户无法完成任务 | 高 |
| 严重问题 | 用户花费大量时间 | 中 |
| 一般问题 | 用户感到困惑 | 低 |
| 建议改进 | 用户提出建议 | 建议 |

### 5.2 问题记录表

| 问题ID | 任务ID | 问题描述 | 类别 | 严重程度 | 建议解决方案 |
|--------|--------|----------|------|----------|--------------|
| I01 | H01 | 按钮位置不明显 | 一般 | 低 | 增大按钮尺寸 |
| I02 | P02 | 速度设置滑块难以精确调整 | 严重 | 中 | 添加数值输入框 |
| I03 | L01 | 搜索框位置不明显 | 一般 | 低 | 搜索框固定显示 |
