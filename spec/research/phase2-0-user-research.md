## 1. 竞品分析

### 1.1 竞品选择

| 竞品 | 定位 | 目标用户 | 价格模式 | 市场份额 |
|------|------|----------|----------|----------|
| Yousician | 游戏化学习 | 零基础-进阶 | Freemium ($19.99/月) | 全球领先 |
| Simply Piano | 钢琴入门 | 零基础 | Freemium ($9.99/月) | 钢琴细分 |
| Flowkey | 曲目学习 | 进阶 | Freemium ($19.99/月) | 曲库优势 |
| SmartMusic | 教育机构 | 教师/学校 | 学校订阅 | B端市场 |

### 1.2 竞品信息架构分析

#### Yousician 信息架构

```
一级导航:
├── Learn (课程学习)
├── Practice (练习模式)
├── Songs (曲库)
├── Profile (个人中心)
└── Settings (设置)

二级页面:
Learn → 课程列表 → 课程详情 → 练习关卡
Songs → 曲目分类 → 曲目详情 → 开始练习
Profile → 练习统计 → 成就徽章 → 设置
```

**优点**：
- 游戏化进度条清晰
- 课程结构化程度高
- 实时反馈动画丰富

**缺点**：
- 进度过快，不适合零基础
- 曲库以课程为主，自由练习受限

#### Simply Piano 信息架构

```
一级导航:
├── Learn (课程)
├── Songs (曲库)
├── Profile (个人中心)

二级页面:
Learn → 课程列表 → 课程详情 → 练习
Songs → 曲目列表 → 曲目详情 → 演奏
```

**优点**：
- 零基础友好
- 多账户支持（家庭）

**缺点**：
- 仅移动端
- 识别准确率不稳定

#### Flowkey 信息架构

```
一级导航:
├── Courses (课程)
├── Songs (曲库)
├── Favorites (收藏)
├── Profile (个人中心)

二级页面:
Courses → 课程分类 → 课程详情 → 视频教程
Songs → 曲目分类 → 曲目详情 → 演奏模式
```

**优点**：
- 曲库大（1000+曲目）
- 视频教程丰富
- 左撇子友好

**缺点**：
- 技术教学弱
- 无实时音准反馈

### 1.3 竞品交互设计分析

| 竞品 | 音准反馈方式 | 位置追踪方式 | 纠错机制 | 评分 |
|------|--------------|--------------|----------|------|
| Yousician | 颜色+动画 | 音频驱动 | 自动重试 | ⭐⭐⭐⭐⭐ |
| Simply Piano | 颜色指示 | 音频驱动 | 提示重试 | ⭐⭐⭐⭐ |
| Flowkey | 无实时反馈 | 手动推进 | 无 | ⭐⭐⭐ |
| SmartMusic | 颜色+数值 | 音频驱动 | 教师评估 | ⭐⭐⭐⭐ |

### 1.4 竞品视觉风格分析

| 竞品 | 主色调 | 设计风格 | 目标人群感受 |
|------|--------|----------|--------------|
| Yousician | 橙色+深蓝 | 游戏化、活力 | 年轻用户喜爱 |
| Simply Piano | 蓝色+白色 | 简洁、友好 | 零基础友好 |
| Flowkey | 黑色+金色 | 专业、优雅 | 进阶用户喜爱 |
| SmartMusic | 蓝色+灰色 | 教育风格 | 教师用户 |

### 1.5 竞品差异化机会

| 差异化点 | 现有竞品缺失 | MusicMaster机会 |
|----------|--------------|------------------|
| 谱子驱动位置追踪 | 全部为音频驱动 | 精准位置追踪 |
| 弦乐支持 | 仅Yousician支持 | 弦乐市场空白 |
| OCR乐谱导入 | 全部不支持 | 用户自有乐谱 |
| 多声部选择 | 全部不支持 | 复杂乐曲练习 |
| 复音检测 | 仅Yousician基础支持 | 键盘精准检测 |

## 2. 用户访谈问题清单

### 2.1 零基础用户访谈问题

**背景问题**：
1. 您目前学习什么乐器？学习多久了？
2. 您平时如何练习？有没有使用过练习APP？
3. 您练习时最大的困难是什么？

**痛点挖掘**：
4. 您在练习时是否知道自己的音准是否正确？
5. 您是否遇到过不知道怎么练的情况？
6. 您是否因为缺乏反馈而放弃练习？

**需求验证**：
7. 如果有一个APP能实时告诉您音准是否正确，您会使用吗？
8. 您希望APP如何帮助您练习？（课程引导/自由练习/纠错）
9. 您愿意为这样的APP付费吗？多少价格合适？

**使用场景**：
10. 您通常在什么时间练习？每次练习多久？
11. 您使用什么设备练习？（手机/平板/电脑）

### 2.2 进阶用户访谈问题

**背景问题**：
1. 您目前学习什么乐器？达到什么水平？
2. 您平时练习的曲目来源是什么？
3. 您使用过哪些练习APP？体验如何？

**痛点挖掘**：
4. 您在练习难点段落时如何攻克？
5. 您是否需要反复练习特定段落？
6. 您如何评估自己的练习效果？

**需求验证**：
7. 如果APP能帮您导入自己的乐谱并练习，您会使用吗？
8. 您需要APP提供哪些统计数据？（时长/准确率/进度）
9. 您希望APP支持哪些乐器？

**使用场景**：
10. 您每周练习几次？每次多久？
11. 您是否需要练习报告导出功能？

### 2.3 教师用户访谈问题

**背景问题**：
1. 您教授什么乐器？学生数量多少？
2. 您如何布置和检查学生练习作业？
3. 您使用过哪些教学辅助工具？

**痛点挖掘**：
4. 您如何追踪学生的练习进度？
5. 学生练习监督的最大困难是什么？
6. 您需要什么样的教学辅助功能？

**需求验证**：
7. 如果APP能帮您追踪学生练习数据，您会使用吗？
8. 您需要哪些班级管理功能？
9. 您愿意为教学版付费吗？

### 2.4 专业用户访谈问题

**背景问题**：
1. 您的专业背景是什么？
2. 您练习的主要目的是什么？（演出/比赛/自我提升）
3. 您对练习工具有什么特殊要求？

**痛点挖掘**：
4. 您在演出前如何准备？
5. 您需要什么样的精准评估？
6. 您是否需要录音对比功能？

**需求验证**：
7. 如果APP能提供高精度音准评估，您会使用吗？
8. 您需要哪些高级功能？（复音检测/表情评分）
9. 您对延迟有什么要求？

## 4. 研究结论

### 4.1 竞品分析结论

1. **差异化定位明确**：谱子驱动位置追踪是核心差异化
2. **弦乐市场空白**：现有竞品主要支持钢琴
3. **OCR导入需求**：用户自有乐谱导入需求未被满足
4. **视觉风格建议**：参考Flowkey的专业优雅风格

### 4.2 用户访谈建议

1. **访谈人数**：每类用户画像2-3人，共8-12人
2. **访谈方式**：线上视频访谈，30-45分钟
3. **访谈时间**：Week 1-2 与 Phase 1 并行执行
